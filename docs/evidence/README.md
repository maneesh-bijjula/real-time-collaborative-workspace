# Capability and evidence index

Results belong to the recorded source, environment, workload and failure model.
A passing functional test does not substitute for a measured capacity target or
an operator's production recovery policy. Historical source-verification files
describe their delivery checkpoints; later releases must identify their own
inputs and pass CI for the exact pushed commit.
